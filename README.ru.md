## Избранные проекты

### [HLS Key Control Utility](https://github.com/Sugo174/HLS-Key-Control-Utility)

Настольная утилита для управления и проверки паролей HLS при персонализации и обслуживании счётчиков электроэнергии с централизованным хранением данных и историей операций.

- Записывает и проверяет пароли HLS по DLMS/COSEM через оптическую головку.
- Проверяет состояние аутентификации прибора после прерванной записи или сброса.
- Хранит зашифрованные значения HLS, историю паролей и журнал операций в общем реестре SQL Server.
- Выгружает подтверждённые партии персонализации в Excel.

**Стек** — Python, PySide6, Gurux DLMS, SQL Server, pyodbc, cryptography, XlsxWriter.

### [Smart Meter Configurator](https://github.com/Sugo174/Smart-electric-meter-configurator)

Настольное приложение для настройки и диагностики счётчиков постоянного тока ЭМИС-ЭЛЕКТРА 977 по RS-485, предназначенное для упрощения настройки, проверки и обслуживания приборов.

- Автоматически определяет адрес Modbus, скорость обмена и чётность.
- Показывает текущие измерения и позволяет настраивать суточное тарифное расписание и постоянную импульсного выхода.
- Заполняет сведения о приборе по отсканированному серийному номеру и синхронизирует часы счётчика с ПК.
- Проверяет запись настроек повторным чтением.
- Поддерживает переносимые сборки для Windows 7 и Windows 10/11 с автоматизированной упаковкой и проверкой обновлений через GitHub Releases.
- Проверен на реальных одноканальных и двухканальных приборах.

**Стек** — Python, Tkinter, MinimalModbus, pySerial, PyInstaller.

### [Telegram Push Notification Bot](https://github.com/Sugo174/Telegram-Push-Bot-For-Smart-Electric-Meter)

Сервер принимает события от счётчиков по TCP, а бот доставляет уведомления подписчикам в Telegram.

- Собирает пакеты, разбитые между чтениями TCP, и обрабатывает несколько пакетов, полученных за одно чтение.
- Расшифровывает биты событий и сохраняет данные в SQLite. Уведомление помечается отправленным после успешного ответа Telegram Bot API.
- Поддерживает подписку на отдельные счётчики и группы. Для управления доступом к группам есть отдельная утилита.
- Предоставляет архив уведомлений и интерфейс на русском, английском и упрощённом китайском.

**Стек** — Python, asyncio, aiohttp, aiosqlite, SQLite, Telegram Bot API.

### [Cat Home Tasker Bot](https://github.com/Sugo174/Cat-Home-Tasker-TGBot)

Telegram-бот для совместного ведения домашних дел с очками опыта и уровнями.

- Позволяет создать домохозяйство или присоединиться к нему по коду приглашения.
- Поддерживает стандартные и пользовательские задачи, профили и историю выполнения.
- Предоставляет административную панель для управления домохозяйствами и пользователями.
- Хранит данные в SQLite. Интерфейс доступен на русском и английском.

**Стек** — Python, aiogram 3, SQLite.
